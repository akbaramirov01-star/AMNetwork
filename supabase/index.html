Уведомления на почту (новая заявка, проверка)

А. Скрипт уведомлений → SQL Editor → New query → вставить → Run.

Б. В Resend → API Keys создай ещё один ключ (имя notify, Sending access). Впиши его и свою почту ниже — команда соберётся здесь на телефоне и никуда не отправится. Потом SQL Editor → New query → вставить → Run.

Ключ хранится только в защищённом хранилище Supabase (Vault). После копирования очисти поле.
