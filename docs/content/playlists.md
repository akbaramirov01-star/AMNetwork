# YouTube / TikTok playlists and numbering (decided 23 Nov 2026)

Channel language is English, so playlist names are English. Every title ends with the series name and its number,
e.g. `… | Stories of the Prophets #16`. The same name goes on the end card. TikTok: same names as TikTok "Playlists"
(Series) where available; otherwise put the series name first in the caption.

Why not one big "Lessons" playlist: separate, clearly named series make people binge the next number ("#2", "#3"),
and YouTube suggests the next video in the same playlist. If a series has fewer than 3 videos after a month, merge
What Would You Do? and True or Myth? into **Muslim Life Lessons**.

Notes
- "50 minor signs" is not a fixed number in the sources — do not promise a count; number them as we make them.
- Major signs: one video each, in the order of the hadith wording; each with the exact source on screen. Dajjal, the beast,
  Gog and Magog are never shown — only landscapes, fog, light.
- Already published videos: rename on YouTube to the new pattern (founder, in YouTube Studio) and add them to the playlist.
