# AM Network — решение по модели (20 ноября 2026)

Решение основателя после разбора go/no-go (ноябрь 2026).

## Что выбрано
1. **Путь: сервис проверки и прозрачности.** Деньги через AM Network не идут.
   Донор отдаёт закят сам (позже — через зарегистрированный фонд-партнёр), мы проверяем семью на месте
   и публикуем открытый отчёт по каждой выплате.
2. **Деньги пилота:** только закят основателя и близких. Открытого сбора нет.
3. **Фонды:** пока не обращаемся. Сначала платформа готова на 100%, потом выходим на фонды
   и благотворительные организации (первый кандидат — Saliheen, Душанбе).
4. **Доход:** в первый год его нет, и это принято. Позже: добровольные чаевые отдельной строкой,
   гранты, плата фондов за сервис проверки — никогда не из закятных денег.

## Что из этого следует
- Блокчейн, токен, NFT, «DAO», Solana и LayerZero из обещаний убираем. Прозрачность даёт публичный журнал выплат
  с контрольными отпечатками (хешами). Base — только позже и только если понадобится.
- Комиссия «1–2,5% ujrah» с закята убирается: по ханафитскому мазхабу частная организация — агент донора, а не амиль.
- «ИИ-оценка 0–100» описывается честно: прозрачный чек-лист нужды с помощью ИИ, решение принимает человек на месте.
- Проверяющие: сотрудники и волонтёры (позже — фонда-партнёра). Имамов не ставим обязательным звеном
  (религиозные организации в Таджикистане под контролем Комитета по делам религии).
- Seed-раунд $150–500 тыс. сейчас не цель; CTO сейчас не нужен.
- Перед пилотом — консультация юриста в Таджикистане и отзыв ханафитского учёного.

## Что значит «платформа готова на 100%»
1. Сайт, вайтпейпер, дорожная карта, презентация и помощник рассказывают одну и ту же новую модель, без противоречий.
2. Заявка семьи → проверка на месте → одобрение → выплата → публичный отчёт работает целиком (Supabase).
3. Кабинеты: проверяющий, админ, донор (видит, куда ушёл его закят), получатель (статус заявки).
4. Публичный журнал выплат без персональных данных семей.
5. Политика конфиденциальности и согласие семьи на обработку данных и фото.
6. Пробный прогон на 2–3 семьях из закята основателя.
