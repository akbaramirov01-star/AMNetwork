# Tajik abridged Sahih al-Bukhari

This local edition contains all 2,230 entries from «Мухтасари Саҳеҳи Бухорӣ», Tajik translation by Abdulhalim Orifi, Dushanbe, «ЭР-граф», 2011, ISBN 978-99947-41-86-1.

The source is an abridgement with its own numbering, so it is exposed as a separate Tajik edition instead of being paired automatically with the 7,563-entry full English/Arabic dataset. This prevents a Tajik translation from being shown beside the wrong Arabic hadith. The text was digitized from the seven PDFs supplied by the project owner; OCR cleanup and source-number validation cover entries 1–2,230.
